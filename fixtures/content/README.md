# Synthetic content-analysis fixtures

Generated by `node scripts/generate-content-fixtures.mjs`. No real secrets, private messages, third-party screenshots or model responses are included. The manifest labels expected policy eligibility (true/false/null), category, language and tuning/held-out split. Posting context is synthetic and explicit.

Cases cover reporting, benign payments, coercion, injection, multilingual/mixed-script text, crop, compression, rotation, watermark and tiny text. Labels need human review before a quality study. They do not establish fraud or model accuracy. Actual images are evaluated; fixture text is not substituted for image perception. No paid evaluation was run when generating this corpus. See `docs/CONTENT_ANALYSIS.md`.
