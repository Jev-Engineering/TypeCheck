# Original synthetic image fixtures

Generated by `scripts/generate-fixtures.py` using Pillow. Simple geometric images created for this project, not downloaded photos or actual prohibited content. Regeneration is optional; the resulting files are included.

`manifest.json` contains 32 labeled comparisons spanning exact, transformed, partial and negative cases. The distinct variants intentionally depict similar shapes in different arrangements; they should not be treated as copies of the reference. A labeled expectation is a test specification, not an observed Jev answer.

No live Jev accuracy measurement has been performed. These fixtures do not replace a representative community corpus. Repeated exact bytes have the same normalized hash and cannot pad the approval sample count. Use separate held-out images and legitimate variation sets for serious calibration.
