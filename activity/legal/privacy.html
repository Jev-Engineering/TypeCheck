JEV / TYPECHECK

Privacy Policy

Effective October 17, 2026

TypeCheck is a Discord bot and Activity hosted by CompleteTech LLC ("we") that checks administrator-configured native message text and images posted in Discord servers, including reference-image matching. Jev is the decision model provided by TypeSafe, a separate provider. This policy explains what TypeCheck processes, why, and for how long.

What we process

  • Images posted in monitored channels. When a member posts or edits a message with an image attachment in a channel an administrator chose to monitor, TypeCheck downloads that image to compare it. Native text moderation is disabled by default. When explicitly enabled with configured text rules, the current message text is submitted directly to TypeSafe for analysis. Empty or unavailable text is not classified safe.
  • Discord identifiers. Server, channel, message, attachment and user IDs connected to each check and any moderation action.
  • Reference images. Images that administrators or delegated moderators upload into TypeCheck as references.
  • Activity sign-in. When you open the TypeCheck Activity, Discord tells us your user ID, your membership in the server and your permissions there. We use this only to decide what you may see and change.
  • Server settings and records. Rules, monitored channels, role grants, moderation logs, audit entries, usage counts and the server's Jev API key (stored encrypted and never shown back).

We do not retain raw submitted message text in jobs, logs, notifications, exports or decision evidence. Configured native text rules analyze it transiently; image-content rules can optionally use posting text as context. We retain a content digest, rule/model/prompt versions, labels, probabilities, thresholds, approval and verification evidence. Digests reveal equality and are not anonymization. Administrator-authored policies, reasons and approval notes are saved configuration; do not paste actual secrets or sensitive messages into those fields.

How text and images are analyzed

Native text uses a separate JSON request and no image rendering. Each rule receives its intended input; mixed results resolve through one policy engine. Links are literal evidence: linked websites, DMs and message history are not fetched. Pasted text and authorized same-server message-link tests never perform Discord moderation. TypeSafe processes selected text under its own terms and retention policies; this application does not guarantee provider zero retention.

Each posted image is resized and normalized, then compared against the server's reference images. Exact matches are found locally. Remaining comparisons are sent to Jev, the decision model provided by TypeSafe, using the server's own Jev API key. TypeSafe processes those requests under its own terms. Based on the result and the server's rules, TypeCheck may log the message, flag it for review, delete it, warn the member or time them out.

How long we keep it

  • Posted images and submitted text are discarded once the check finishes; digest-based decision records follow the configured retention rules.
  • Moderation logs, evaluations and audit entries are kept for the period each server sets, between 1 and 365 days (30 days by default).
  • Background job records are deleted after 7 days. Detailed usage records are deleted after 100 days and daily usage totals after 400 days.
  • Reference images are kept until an administrator removes them.
  • Attachment and action identifiers that prevent the same message from being processed or punished twice may be kept for as long as the server uses TypeCheck.
  • Activity sessions expire after 15 minutes.

Optional review and training permissions

Data-use notice version: 2026-10-17.1. Server owners and administrators can save two separate, optional choices in Settings. Both local permissions default to off, including for existing servers. Neither is required for moderation. Administrators must have authority to share the affected data; these choices do not replace the rights or consent of the people whose data is processed.

  • TypeSafe / Jev review and analysis. This records the server's permission for TypeSafe to read and analyze inputs and outputs to understand model issues and debug use cases. TypeSafe's model-improvement announcement says these queries are not used for training. The actual “Help improve TypeSafe models” setting is managed in the TypeSafe console by the API-key owner's organization and applies across that organization. TypeCheck cannot change or verify that setting. Checking this box does not enable provider review, and unchecking it does not override an organization opt-in. The API-key owner must manage that setting separately.
  • CompleteTech LLC training. This separately records permission for the service host to use data processed by TypeCheck for model training and improvement. This release has no training-data collection, export or training pipeline; saving permission does not start those activities or extend retention. Any future collection requires a notice describing the data, purpose and retention before activation.

Uncheck either choice and save to withdraw that local permission. We record changes with the administrator's Discord ID, server ID, timestamp, previous and current choices, and notice version in the server's audit log, subject to its configured retention. Current choices remain in server settings until changed or the server's stored data is deleted. Discarded text and images cannot be recovered by opting in. Ordinary processing by TypeSafe remains subject to its own terms and retention policies regardless of these optional choices.

What we don't do

  • We don't sell or rent data, show ads, or use data for profiling or advertising.
  • We don't use cookies or browser storage for tracking.
  • We don't share data except with the providers needed to run TypeCheck: Discord, TypeSafe (Jev), and our hosting provider (GoDaddy, United States). We may also disclose data when the law requires it.

Security

Each server's data is kept separate, Jev API keys are encrypted at rest, reference images are kept in private storage, and access in the Activity is checked against your live Discord permissions. No system is perfectly secure, and TypeCheck is still experimental software.

Your choices

  • Server administrators choose which channels are monitored, set retention, and can delete reference images. Removing TypeCheck from a server stops all new processing there.
  • To request deletion of a server's stored data, or for questions about data about you, contact the server's administrators. They can coordinate with the service host, CompleteTech LLC, to confirm the deletion process and any applicable backup-retention limits.
  • TypeCheck is for use in Discord, which requires users to meet its minimum age. We don't knowingly collect data from children below that age.

Changes

We'll update the date above when this policy changes. Continued use of TypeCheck after a change means the updated policy applies.

Continued use does not grant either optional data-use permission. Material changes to an optional purpose require a new explicit choice under the revised notice; existing permission must not be treated as permission for a new purpose.
