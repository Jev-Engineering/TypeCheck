# Product graphics

`typecheck-banner.svg` is the editable, reproducible text-and-image banner in the existing ink/pink identity. README references this source directly. Prior image-only raster banners are retired; originals remain in Git history. Reviewed scam references remain unchanged.

Discord portal art in `discord/` (Rich Presence cover, Activity cover, bot banner, app icon and logo) is generated by `python scripts/generate-discord-assets.py` (Playwright + Pillow; not bot dependencies). It renders HTML/SVG in the TypeSafe paper/ink theme: palette ink `#1E1E1E`, paper `#FEFEFE`, pink `#F386A1`, panel `#DEDEDE`; the self-hosted OFL fonts in `activity/fonts/` (Schibsted Grotesk, VT323, JetBrains Mono); square retro windows, a computed halftone and fixed-seed grain. Output is deterministic and keeps each file's name, size and format. The brand mark is the pink tile with an ink VT323 "J". Prior artwork remains in Git history.

Native text screenshots: `evidence/issue39-*.png`, generated by `scripts/browser-smoke.py` with `BROWSER_EVIDENCE_PREFIX=issue39-`. They show the compiled implemented UI under an offline synthetic transport and are labeled accordingly. They are not production screenshots, Discord authentication proof or provider acceptance.
